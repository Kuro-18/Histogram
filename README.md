# 📊 Filipino Social Media Usage Histogram

This project visualizes social media usage in the Philippines using a histogram created with Python.

## 🧰 Tools Used

* Python
* NumPy
* Matplotlib
* Visual Studio Code

## 📈 What It Does

* Generates simulated data representing social media usage of Filipino users
* Displays a histogram showing the distribution of usage percentages
* Calculates and shows the average (mean) usage

## ▶️ How to Run

1. Install dependencies:

   ```bash
   pip install numpy matplotlib
   ```
2. Run the Python file:

   ```bash
   python histogram.py
   ```

## 📁 Output

* A histogram graph displayed on screen
* Optional saved image file (`filipino_social_media_histogram.png`)

## 📌 Notes

* Data used is simulated for demonstration purposes only
* Can be replaced with real dataset for research use
